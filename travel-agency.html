✈️ Lodging & Travel Agency Application

A Java application designed to manage lodging, customers, employees, and travel agency operations using object-oriented programming and MySQL.

📌 Project Overview

The Lodging & Travel Agency Application is a Java-based application that manages information related to customers, lodging, employees, and travel agency operations.

The project demonstrates object-oriented programming, database development, and the integration of a Java application with a MySQL database.

🛠️ Technologies Used

Java MySQL JDBC Object-Oriented Programming Database Development NetBeans

⚙️ Key Features

  • Customer management
  • Employee management
  • Lodging management
  • Hotel and house information
  • Travel agency functionality
  • MySQL database integration
  • Java object-oriented class structure
  • Database connectivity using JDBC

💻 What I Learned

This project strengthened my understanding of Java object-oriented programming by requiring multiple classes to work together as part of a larger application.

I also gained experience working with relational databases and connecting Java applications to MySQL. This helped me understand how applications can store, retrieve, and manage persistent data.

🎯 Project Highlights

This project combines application development with database management to create a system that could support the operations of a lodging and travel agency.
