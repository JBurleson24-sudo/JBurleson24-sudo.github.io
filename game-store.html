🎮 Video Game Store Management System

A desktop application designed to manage video game store operations, products, accounts, and application navigation.

📌 Project Overview

The Video Game Store Management System is a Windows Forms application developed in C# and .NET. The application provides functionality for managing a video game store through a graphical user interface.

This project demonstrates my ability to develop desktop applications, create user interfaces, organize application navigation, and implement functionality using C#.

🛠️ Technologies Used

C# .NET Windows Forms Visual Studio Object-Oriented Programming File Handling

⚙️ Key Features

  • User interface designed with Windows Forms
  • Application navigation between different screens
  • Account management functionality
  • Video game and product management
  • File handling
  • Organized C# application structure
  • Desktop application development using .NET

💻 What I Learned

This project gave me practical experience developing a complete desktop application in C#. I worked with Windows Forms to create the user interface and learned how to connect different parts of an application through navigation and event-driven programming.

The project also helped strengthen my understanding of object-oriented programming, file handling, application organization, and designing software around a specific business scenario.

🎯 Project Highlights

The goal of the project was to create a functional management system that could be used as the foundation for operating a video game store.
