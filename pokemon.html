⚡ Interactive Pokémon Application

A Unity-based interactive application developed with C# featuring a Pokémon-themed study experience, video playback, and an interactive quiz system.

📌 Project Overview

The Interactive Pokémon Application is a Unity project developed using C#. The application combines an interactive user interface with a Pokémon-themed learning and quiz experience.

The project includes multiple screens that allow users to navigate through the application, study material, watch video content, and complete an interactive quiz.

🛠️ Technologies Used

C# Unity Unity UI Video Player C# Scripting Game Development

⚙️ Key Features

  • Pokémon-themed interactive interface
  • Main menu navigation
  • Study screen
  • Interactive quiz system
  • Multiple quiz questions and answers
  • Pass and fail screens
  • Video playback functionality
  • Play, pause, and rewind video controls
  • Camera-based screen navigation
  • C# scripts controlling application behavior
